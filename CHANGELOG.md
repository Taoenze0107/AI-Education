# Version 1.1.0 — accessible revision

- Added guided evidence entry with optional advanced JSON, matching examples for all three experiments, and custom experiment selection.
- Connected every existing API operation to the interface, including explicit session creation, session browsing/pagination, detailed histories, outcome recording, knowledge browsing/search/reload, and service status.
- Added direct access to all four teaching hints and the full explanation, without requiring extra attempts.
- Added complete session JSON export and restoration after a browser refresh. Earlier attempts remain available for inspection and outcome recording.
- Added keyboard navigation, visible focus, a skip link, labelled controls, grouped inputs, linked validation errors, live status messages, responsive layouts, and reduced-motion/forced-colors styles.
- Added session-list and knowledge-document API endpoints, finite-number and whitespace validation, and safer knowledge reloads that preserve the last valid library on failure.
- Added macOS, Linux, and Windows launchers; rule-based operation requires no API key. Improved package data and Docker persistence configuration.
- Included backend and browser regression tests, setup instructions, and verification notes.

The original project folder is separate from this revised copy. The interface and teaching content remain in Chinese, with English quick-start instructions.
