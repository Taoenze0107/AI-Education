    完成一次学习循环
    
            
      

    1. 先预测，再体验模型。在交互实验目录选题，回答预测问题，再播放动画、调整参数。体验模型不需要填写记录编号。
      2. 

    2. 记录自己的实测。到准备记录选择实验并填写匿名编号，按表头保留原始读数与单位。模型输出与教学样例都不是真实测量。
      3. 

    3. 核对证据与计算。检查实验条件，记录观察，写出自己的换算、代入过程和结果，再提交诊断。也可从图中的数据点或公式向助教提问。
      4. 

    4. 修正后，再验证一次。根据提示核对数据与步骤，记录改了什么；回到交互课完成“再验证”，判断自己能否解释新的情境。
      5. 

    5. 从历史记录继续。在历史记录对比每轮输入、反馈和修改，查看待复习的问题。登录后可跨设备找回账号内已保存的记录。
      6. 

    
            
    
              键盘与屏幕阅读器使用
              
    
                按 Tab
                依次访问链接和控件；页面首个链接可跳到主要内容。使用方向键选择单选项，使用
                Enter
                或空格展开详细内容。错误会集中列出并提供跳转链接，处理状态会自动播报。页面支持浏览器缩放和窄屏布局。
              
    
            
    
            
    
              证据与公式填写说明
              
    
                三路证据均可独立关闭。空白结果表示未提供，而不是零。置信度使用 0
                到 1 的小数；允许误差使用 0 到 100
                的百分数。公式中的每个变量都应提供统一单位后的数值，例如 20 mA
                填为 0.02 A。
              
    
              
    
                数学表达式支持
                sqrt、log、ln、log10、exp、sin、cos、tan、abs，以及常量 pi 和
                e。普通使用无需 JSON；高级模式可直接编辑全部请求字段。
