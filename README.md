# 实验学习助手 · 教师班级版

面向大学物理实验的学习与教学工具。学生按准备、数据、证据、计算、诊断、修正逐步完成实验；教师建立班级、发布任务、查看提交版本和修改过程，并汇总班级共性问题。

## 功能

- 128 个实验主题，504 组教学模拟数据，1512 道练习，393 条知识库资料。
- 原始数据输入和表格导入、图线展示、单位与公式核查、分级学习提示。
- 本地数学公式排版，支持手机宽度浏览。
- 教师/学生账号、班级邀请码、作业要求和截止时间、版本化提交、教师反馈。
- 提交进度、待批阅和需修改筛选、常见问题分布、CSV 名册导出。
- 按账号或浏览器隔离记录。教师只能查看本班学生主动提交的作业版本。

示例数据均为教学模拟数据，不能当作真实仪器测量。

## 本地启动

需要 Python 3.11 或更新版本。

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
python -m uvicorn app.main:app --host 127.0.0.1 --port 8002
```

打开 http://127.0.0.1:8002/；班级空间位于 `/classroom`。创建教师账号后建立班级，再邀请学生使用各自的学生账号加入。

Windows 可使用项目内的 `start.cmd`；macOS 提供启动脚本。不同启动脚本的默认端口可能为 8000，请以实际输出地址为准。

默认不启用外部大模型。需要使用时，在本机或托管平台设置 `OPENAI_API_KEY` 与 `ENABLE_LLM=true`，不要将真实密钥提交到仓库。

## 数据和配置

- `app/data/`：项目自带的实验资料、教材对照及知识库，应随源码保留。
- `data/`：运行时 SQLite 数据库，由程序初始化。该目录不上传 GitHub。
- `.env`：本机配置，不上传 GitHub；仓库只提供空白配置示例 `.env.example`。
- 班级提交保留提交当时的完整过程。之后的私人修改不会改变已交版本，再次提交会形成新版本。
- 截止后仍允许提交并标记迟交；教师可结束或重新开放收集。

详见 [教师班级版使用说明](教师班级版使用说明.md)、[快速启动说明](QUICKSTART.md) 和 [知识来源](KNOWLEDGE_SOURCES.md)。

## 验证

```sh
python -m pip install '.[dev]'
python -m pytest -q
```

教师班级版已通过 363 项后端测试，覆盖账号/班级隔离、提交版本、教师反馈、截止时间、CSV 安全和旧记录归属。浏览器中验证了完整师生流程和 375 像素宽度展示。

## 部署

这是包含 Python 后端的应用。部署时运行 `uvicorn app.main:app --host 0.0.0.0 --port "$PORT"`，配置 HTTPS、持久数据库目录和数据库备份。GitHub 用于保存与更新源码；当前 ngrok 连接仍依赖本机网站服务运行。

仓库不包含真实学生记录、账号数据库、登录 Cookie 或本机 API 密钥。
